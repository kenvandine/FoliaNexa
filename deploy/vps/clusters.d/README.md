# clusters.d/

One `.caddy` file per independent private cluster this VPS proxy fans out
to (PLAN.md §7D) — generated by `../add-cluster.sh`, imported by
`../Caddyfile`'s `import clusters.d/*.caddy`.

These files aren't checked into git (see the root `.gitignore`) — they're
real operator domains and WireGuard-tunnel addresses, generated on the VPS
itself the same way `setup-wireguard.sh`'s `peers.d/` is. This README is
the only tracked file in this directory, so the directory itself still
exists in a fresh checkout.

```bash
../add-cluster.sh --id domain1 \
  --admin-domain admin.domain1.com --api-domain api.domain1.com \
  --play-domain play.domain1.com --mgmt-upstream 10.66.0.2:8443
```

Re-running for the same `--id` regenerates only that one file — adding or
updating one cluster never disturbs another's. To remove a cluster,
delete its file (`rm clusters.d/<id>.caddy`) and reload Caddy.
